# ZKBZ 标准 PDF 下载 — 全功能测试计划与测试用例

> 版本：对照应用 v3.1.0 / 前端 v4.3.3  
> 分支：`谭-文件下载`  
> 适用范围：功能验收、回归、发布前检查  

---

## 1. 测试目标

验证系统在 **数据库驱动（MySQL）** 模式下，各模块检索、筛选、下载与界面交互正确；重点确认近期改动：

1. 双工作流（先查询后筛选 / 先筛选后查询）
2. 术语检索（含 AI/本地语义扩展）
3. 取消「扫描磁盘」后仅走库内路径
4. PDF 标准号+年份校验（防错挂）
5. 同标准号不同文件名去重（只展示一条）

---

## 2. 测试环境

| 项 | 要求 |
|----|------|
| 系统 | Windows 10/11 |
| Python | 3.11+ |
| 数据库 | MySQL（`.env` 中 `MYSQL_*` 已配置且可连） |
| 服务地址 | http://127.0.0.1:5000/ |
| 浏览器 | Chrome / Edge 最新稳定版 |
| PDF 目录 | 可选；未配置时检索仍可用，下载可能显示「磁盘未找到」 |

**启动：**

```bat
启动ZKBZ.bat
```

或：

```bat
py -3 backend\run.py
```

**自动化冒烟（可选）：**

```bat
py -3 scripts\run_feature_tests.py
```

## 4. 通过准则

- **阻断（P0）**：数据库连不上、主检索不可用、错误工作流未拦截、错挂旧版 PDF、重复文件仍双条展示
- **严重（P1）**：下载失败（库内有记录且文件存在时）、术语/产品模块不可用、多项下载异常
- **一般（P2）**：文案、空状态提示、分页样式
- **通过条件**：全部 P0/P1 用例通过；P2 遗留不超过 3 条且有记录

### 6.5 PDF 文件质量（TC-F）— 近期缺陷回归

| ID | 用例 | 步骤 | 预期 | 优先级 |
|----|------|------|------|--------|
| TC-F01 | 年份错挂 — 稀土 | 搜 `GB/T 13748.8-2026`，展开 | **不出现** `…1992…测定铜量`、`…2005…` 等异年版 | P0 |
| TC-F02 | 年份错挂 — 莲子 | 搜 `GB/T 18525.4-2026`，展开 | **不出现** `…2001…枸杞干葡萄干…` | P0 |
| TC-F03 | 年份错挂 — 镁合金 | 搜 `GB/T 13748.3-2026`，展开 | **不出现** 1992/2005 旧版 PDF | P0 |
| TC-F04 | 同年合法保留 | 若库内有正确同年文件 | 可正常列出并下载（文件存在时） | P0 |
| TC-F05 | 重复去重 | 打开含 `12005.2-1989` 的标准详情 | `GBT 12005.2-1989_F_…` 与 `GBT12005.2-1989 …` **只显示 1 条**；优先更大体积 | P0 |
| TC-F06 | 下载拦截错挂 | 若直接请求错挂 file_id（有条件时） | 接口拒绝「编号/年份不匹配」 | P1 |
| TC-F07 | 无 PDF 空态 | 无可用文件的标准 | 「暂无文件」或「磁盘未找到」，不崩溃 | P1 |
